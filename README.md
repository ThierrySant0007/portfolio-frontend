# Portfólio Pessoal (Frontend) ✨

Este é o repositório do frontend do meu portfólio pessoal, desenvolvido para apresentar meus projetos, habilidades e fornecer uma forma de contato. O projeto possui um design moderno estilo *glassmorphism*, é totalmente responsivo e foi construído com as melhores práticas de UI/UX.

## 🛠️ Tecnologias Utilizadas

- **React** (Biblioteca principal)
- **TypeScript** (Tipagem estática para maior segurança e produtividade)
- **Vite** (Build tool super rápido)
- **Tailwind CSS** + **CSS Vanilla** (Para estilos globais, responsividade e glassmorphism)
- **Lucide React** & **React Icons** (Ícones modernos)
- **Web3Forms** (Integração sem backend para envio de formulário de contato por e-mail)

## ⚙️ Principais Funcionalidades

- **Design Premium:** Cores sofisticadas e micro-interações elegantes.
- **Lista de Projetos:** Uma galeria completa dos projetos em destaque.
- **Painel de Administração:** Uma interface interna protegida para (futura) edição de conteúdo.
- **Formulário Funcional:** Seção de contato com validação e envio real via Web3Forms.
- **Responsividade:** Totalmente otimizado para celulares, tablets e desktops.

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- **Node.js** (versão 18 ou superior)
- Gerenciador de pacotes (npm, yarn, ou pnpm)

### Passo a Passo

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/ThierrySant0007/portfolio-frontend.git
   cd portfolio-frontend
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. Acesse no seu navegador através do endereço: `http://localhost:5173`
